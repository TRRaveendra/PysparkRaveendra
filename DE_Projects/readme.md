## 📚 Data Engineering Projects – Databricks DBC Files

This repository contains **Databricks DBC files** for the Data Engineering projects covered in the YouTube training series.

### 🚀 How to Use

1. Download the required **DBC file** from this repository.
2. Import the DBC file into your **Databricks Workspace**.
3. Follow the corresponding YouTube video to understand the project step by step.
4. Practice the implementation in your own Databricks environment.
